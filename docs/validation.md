# Что проверено

Локальная проверка выполнена **5 ноября 2026** без скачивания библиотек и весов:

```bash
python3 scripts/verify_static.py
```

- Интерпретатор: Python 3.12.3.
- Все Python-файлы компилируются; дополнительно AST проверяется грамматикой Python 3.11.
- Все 10 кодовых ячеек notebook компилируются как обычный Python, без непроверяемых magics.
- Notebook JSON корректен, outputs пустые, GPU metadata отключены.
- Импорт публичного пакета/Weights не требует NumPy/PyTorch и не выбирает GPU.
- 18 unit-тестов проходят: схемы точек/позы/классов, расписание RePaint,
  проверка шести весов, ограничение subset, сохранение мерок, отказ при неверной
  схеме, отделение target от генерации, возобновление успехов/повтор ошибок,
  запрет смешивания sampling-конфигураций, запись ошибки при fail-fast,
  tensor-only CPU loading, строгая загрузка и отказ при несовпадении checkpoint.

Тесты экспорта/оценки/checkpoint loader используют небольшие test doubles
изображений, pipeline и torch.load; они проверяют управляющую логику,
**не** предсказывают качество модели и не загружают настоящий checkpoint.

## Что ещё требует Kaggle

`scripts/check_runtime.py` добавлен в ноутбук для проверки на CPU после установки:
LIP mapping, mock ONNX/pose adapters, преобразование landmarks, one-hot, identity/degenerate TPS,
forward KG/PG/SCI на небольших синтетических входах. Он не требует checkpoint и
не запускает pretrained inference. Локально этот скрипт только компилировался.

Не проверялись локально:

- Разрешение и установка полного набора ML-зависимостей.
- Фактическое исполнение под отдельным интерпретатором Python 3.11.
- Скачивание/содержимое KGI archives и загрузка всех настоящих checkpoints.
- HRNet/OpenPose/SCHP inference и соответствие авторским аннотациям.
- Pretrained KG/PG/SCI forward, численная устойчивость на реальных фото,
  CUDA/FP16, расход RAM/VRAM, скорость.
- Загрузка FITVTO-1k и метрики на настоящей выборке.

Числовых результатов качества в репозитории нет. Notebook предоставляет
последовательность для их получения и сохраняет реальные ошибки вместо
подстановки демонстрационных изображений или фиктивных метрик.
